# Week 11 - Local fixture persistence

## Aim

Write and read the three fixed local playlist lines.

## Procedure

1. Create the fixed pipe-delimited fixture lines.
2. Write `playlist_fixture.txt` in this week folder.
3. Read the same file back with UTF-8.
4. Compare rows exactly, compile, run, and retain the file.

## Scope boundary

The text file has no links, media, accounts, or real-world data.
