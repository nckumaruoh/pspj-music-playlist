# Week 02 - Fixture validation

## Aim

Validate one fictional title and practice-play count.

## Procedure

1. Match titles against the fixed list of three labels.
2. Accept an integer play count from zero through nine.
3. Identify the fixed text token `two` as rejected.
4. Compile, run, and compare output.

## Scope boundary

All validation is local and uses invented fixture values only.
