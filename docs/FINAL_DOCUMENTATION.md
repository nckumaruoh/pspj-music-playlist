# Classroom Playlist Lab - Final Documentation

## Project purpose

This PSPJ learning artifact builds a deterministic Java console program in twelve weekly increments. All fixture titles, studios, durations, and counters are invented solely for reproducible classroom programming practice.

## Weekly progression

| Week | Programming evidence |
| --- | --- |
| 01 | Console baseline |
| 02 | Title and count validation |
| 03 | Totals, average, and decision rule |
| 04 | Scripted command loop |
| 05 | Reusable lookup method |
| 06 | Array search |
| 07 | Edge-case checks |
| 08 | Recursive duration total |
| 09 | Track and playlist objects |
| 10 | Format exception recovery |
| 11 | Local fixture file verification |
| 12 | Collection and stream summary |

## How to verify

Compile and run the Java class in each `week-XX` folder with Java 21. Compare console output exactly with `OUTPUT.txt`. Week 11 regenerates `playlist_fixture.txt` locally and verifies the saved rows.

## Quality controls

- Fully offline, fixed ASCII-only fixture data.
- No streaming, downloads, accounts, personal data, clocks, or randomness.
- Every week has a procedure, trace, source file, and output proof.

## Final result

The final collection report verifies three tracks, 530 total seconds, six practice plays, and Neon Orbit as the fixed most-played fixture.
